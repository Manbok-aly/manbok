## 자기소개

### 글과 사진 기록하기
- `index.html`을 열고 상단 또는 각 카테고리의 **글쓰기**를 누릅니다.
- 카테고리와 제목을 입력하고, 내용이나 사진을 추가한 뒤 **게시하기**를 누릅니다.
- 사진은 JPG, PNG, WebP, GIF 형식으로 최대 6장, 장당 5MB, 합계 20MB까지 첨부할 수 있습니다. 미리보기에서 개별 사진을 제거할 수 있습니다.
- 게시물의 **자세히 보기**에서 본문과 사진을 확인하고 **수정**, **삭제**할 수 있습니다.
- 글과 사진은 IndexedDB에 저장되어 같은 브라우저와 같은 사이트 주소에서 새로고침해도 유지됩니다. 브라우저 데이터 삭제 시 사라질 수 있으며, 비공개 모드에서는 세션 종료 시 삭제될 수 있습니다.
- 현재는 브라우저 로컬 기록 기능입니다. 다른 기기나 방문자에게 게시물을 공개하려면 인증, 게시물 API, 공용 데이터베이스 및 사진 저장소를 별도로 연결해야 합니다. 저장소에 커밋되는 콘텐츠는 아닙니다.
