# 시간복잡도 정리

## 시간복잡도 점근 표기법 학습

### 시간복잡도

시간복잡도란 간단하게
`시간복잡도 = 입력크기 n에 대한 방정식` 이라고 할수있다.

이런 시간복잡도는 보통 최악의 경우로 기본연산 시간을 정리해서 따진다.

```md
### 기본연산시간

기본연산시간이란 일반 산술연산(+,=,/,\*,%) 그리고 비트연산(&,|,^,~,<<,>> 등등)
대입연산자까지 포함하는 경우도 있다고한다.
```

이런 기본 연산시간 n에 대해 알고리즘 동작에 필요한 시간을 n에 대한 수식으로 포현한것이 바로 시간복잡도이다.

`ex-1`
```c
#include <stdio.h>

int main(void)
{
    int n = 5;

    for (int i = 0; i < n; i++)
    {
        printf("%d\n", i);
    }

    return 0;
}

```
임의로 예시를 c로 하나 작성해보았다.
해당 코드에서 보면 0부터 4까지 출력하는 반복문이다.
이런 간단한 연산은 입력값 N에 따른 출력값이 선형적으로 변화한다.

하지만 중첩 반복문을 이용한다면 어떻게 될까

```c
#include <stdio.h>

int main(void) {
    for (int i = 2; i <= 9; i++) {
        for (int j = 1; j <= 9; j++) {
            printf("%d x %d = %d\n", i, j, i * j);
        }
        printf("\n");
    }
    return 0;
}
```
구구단을 출력하는 중첩반복문을 작성해보았다.
